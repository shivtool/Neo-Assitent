# Neo Assistant

Hindi आवाज़-सहायक Android ऐप (Kotlin + Jetpack Compose)।

## Android Studio में खोलना
1. Android Studio → **Open** → इस फ़ोल्डर (`neo`) को चुनें।
2. पहली बार खुलने पर Gradle sync में समय लगेगा (यह `gradle-wrapper.jar` अपने आप डाउनलोड कर लेगा — इंटरनेट चाहिए)।
3. **Run ▶** दबाकर असली फ़ोन या एमुलेटर (minSdk 26 / Android 8+) पर चलाएँ।

## पहली बार ऐप खोलने पर
Settings (⚙️) में जाकर ये तीन परमिशन ज़रूर ऑन करें:
- **Mic, Contacts, Phone** — बोलकर कमांड देने, कॉन्टैक्ट खोजने और कॉल करने के लिए।
- **Accessibility Service** — सिर्फ़ "स्क्रीन लॉक करो" कमांड के लिए (Neo स्क्रीन का कंटेंट नहीं पढ़ती)।
- **Modify System Settings** — "ब्राइटनेस बढ़ाओ/घटाओ" कमांड के लिए।

## सपोर्टेड कमांड (उदाहरण)

- "जीमेल खोलो" / "पापा को मेल भेजो"
- "स्क्रीन लॉक करो"
- "ब्राइटनेस 50 प्रतिशत" / "ब्राइटनेस बढ़ाओ"
- "कैमरा खोलो", "व्हाट्सएप खोलो", या फ़ोन में इंस्टॉल किसी भी ऐप का नाम

## डिज़ाइन के फ़ैसले
- **कोर/सिस्टम ऐप ब्लॉक हैं**: `AppIndex.kt` में `OPEN_PREINSTALLED_APPS = false` — Neo सिर्फ़ यूज़र-इंस्टॉल्ड ऐप्स (और अपडेटेड सिस्टम ऐप्स जैसे Chrome/YouTube) खोलती है, ताकि Settings/System UI जैसे कोर ऐप हाथ न लगें। इसे बदलने के लिए वही एक लाइन बदलें।
- **हिंदी/इंग्लिश दोनों में नाम पहचान**: `TextTools.kt` का फ़ोनेटिक "skeleton" मैचर — "कीर्ति", "Keerti", "Kirti" सबको एक जैसा मानता है, फ़ज़ी मैचिंग के साथ।
- **कोई मेमोरी लीक नहीं**: SpeechRecognizer/TextToSpeech/background executor सब `onDestroy()` में साफ़ होते हैं; `onStop()` में रिकग्निशन कैंसल होता है; कोई static Activity reference नहीं रखी गई (सिर्फ़ Accessibility Service का इंस्टेंस, जो `onUnbind`/`onDestroy` में साफ़ होता है)।
- **कभी क्रैश नहीं**: हर `startActivity` कॉल try/catch में है और missing ऐप/परमिशन पर बोलकर बताती है, टूटती नहीं।

## ⚠️ ज़रूरी सीमाएँ (कृपया पढ़ें)
- इस सैंडबॉक्स में Android SDK/Gradle डाउनलोड करने के लिए इंटरनेट एक्सेस नहीं है, इसलिए मैं यहाँ असली APK बनाकर टेस्ट नहीं कर सका। हर फ़ाइल को ध्यान से लिखा और हाथ से जाँचा (brace/paren बैलेंस, cross-file API मिलान) है, लेकिन **कृपया Android Studio में एक बार Run ज़रूर करें** — किसी डिवाइस-specific दिक़्क़त (जैसे किसी OEM पर Accessibility सेटिंग का नाम अलग होना) का पता वहीं चलेगा।
- `GEMINI_API_KEY` जैसी कोई hard-coded key अब कोड में नहीं है (पुरानी फ़ाइल में थी) — अगर आपको AI-आधारित समझ (fallback) चाहिए तो अलग से बताइए, मैं वह हिस्सा सुरक्षित तरीक़े से (जैसे local.properties से key लेकर) जोड़ दूँगा।
- Accessibility सेवा *सिर्फ़* लॉक करने के लिए है — Play Store की नीति में इसका सही कारण Settings में साफ़ लिखा है (`accessibility_service_description`)।
